# Images Directory

Place your images here for use in the portfolio site.

## Recommended Structure

- `profile.jpg` - Your profile/headshot photo
- `projects/` - Screenshots or images of your projects
- `icons/` - Any icons or small graphics
- `background/` - Background images if needed

## Image Optimization Tips

- Use appropriate formats: JPG for photos, PNG for graphics with transparency, SVG for logos
- Optimize images for web to reduce file size
- Use responsive images where appropriate
- Consider using a CDN for larger sites
